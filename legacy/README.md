# Preserved earlier toolkit components

Files retired from the active static conversion pipeline are preserved here byte-for-byte from commit 7f7c764. This includes the original converter source snapshot, OBJtoM2.exe, the previous conversion tests and asset-specific helper scripts.

These are historical reference files, not the current build entry point. Use ../obj-to-m2-toolkit/scripts/pipeline.py and the current README for new static conversions. Original authorship and source notices remain intact; see ../obj-to-m2-toolkit/CREDITS.md and THIRD_PARTY_NOTICES.md.

Keeping this material does not reintroduce asset-specific behavior into the active exporter. The existing proof-of-concept MPQ remains in the active toolkit's proof-of-concept directory, unchanged.
